# # イジンデン 偉人伝編纂録（GitHub Pages版）

このファイル一式は、Claude上で動くアプリを**GitHub Pagesで自分だけの
ウェブサイトとして公開する**ためのバージョンです。

## Claude版との違い

| 項目 | Claude内版 | GitHub Pages版 |
|---|---|---|
| データ保存 | Claudeのストレージ機能 | **ブラウザのlocalStorage**（この端末・このブラウザのみ） |
| AIアドバイス | 追加設定不要 | **自分のAnthropic APIキーが必要** |

- 所持カード・デッキのデータは、あなたが使っているブラウザの中だけに保存されます。
  他の端末やブラウザとは共有されません。ブラウザの閲覧データ（サイトデータ）を
  消去すると失われるのでご注意ください。
- AIアドバイス機能を使うには、[console.anthropic.com](https://console.anthropic.com/settings/keys)
  でAPIキーを発行し、アプリ内の「デッキ構築」タブにある「APIキー」欄に入力・保存してください。
  キーはブラウザのlocalStorageに保存されるだけで、GitHubリポジトリやサーバーには
  一切送信・保存されません。ただし、**このAPIキーはブラウザの開発者ツール（ネットワークタブ）
  から見ようと思えば見える状態になります**。自分だけが使う前提で、他人と共有しない
  ようにしてください（APIキーをコードに直接書き込んでコミットするのは絶対にやめましょう）。

## 公開手順（GitHub Pages）

1. GitHubで新しいリポジトリを作成します（例：`ijinden-deck-lab`）。Public/Privateどちらでも
   Pagesは使えますが、Privateリポジトリで無料でPagesを使うにはGitHub Proプランが必要な場合があります。
   個人利用なら基本的にPublicで問題ありません（ソースコードは公開されますが、
   APIキーやあなたの所持カードデータはリポジトリに含まれないので安全です）。
2. リポジトリ内に `index.html` という名前でこのファイル（`ijinden_deck_lab_github.html`の中身）
   を配置してコミット・プッシュします。
3. GitHubのリポジトリ画面で `Settings` → `Pages` を開きます。
4. `Source` を `Deploy from a branch` にし、ブランチを `main`（または`master`）、
   フォルダを `/ (root)` に設定して `Save` を押します。
5. 数分待つと `https://<あなたのユーザー名>.github.io/<リポジトリ名>/` で公開されます。

## 補足：複数端末で同期したい場合

localStorageは端末・ブラウザごとに独立しているため、スマホとPCなど複数端末で
所持カードやデッキを同期させることはできません。同期が必要な場合は、
Firebase（Firestore）やSupabaseなどの無料枠があるバックエンドサービスと
組み合わせてデータを保存する仕組みを別途追加する必要があります。
必要であれば、その改修もお手伝いできます。
